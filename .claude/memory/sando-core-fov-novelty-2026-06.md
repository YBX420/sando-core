**2026-06-30 novelty workflow (SOTA survey + adversarial prior-art vetting) for FOV-limited certified fastest-safe go-around. Only CCF rated genuinely novel; the other 4 ideas are incremental recombinations.**

**CCF (Certified Commitment Function) = the headline** (塔菲大人 picked it 2026-06-30, CCF-only). Replace the stateless per-tick fastest-safe tournament with a state machine keyed on the committed homotopy σ: (1) HOLD σ, run the SLIP s-search for the fastest `s∈[s_min,1]` keeping σ's continuous-time deficit `m_σ≥0` (restore margin by yielding-behind, NEVER by switching); (2) only if NO s certifies σ (its feasible-speed interval empties) re-open the full L/R/over tournament, count ONE switch, with a K-tick debounce sized from KF covariance (`Δ=2R·σ_pos`, linearized — note margin is distance²). Switch trigger = HARD certificate feasibility, not a goal-ward speed deadband. ~40-80 lines Python: wrap the tournament (`ego_maneuver.py`, keyed on `last_kind`), reuse `_cert_clear` + the SLIP substitution (`obs_vel=v/s, obs_acc=a/s², t_hi=s·TAU`; see `test_retime.py`), repurpose the dead `_MAN_STATE`/`MAN_DEADBAND` hooks + the existing switch counter. ONE `ego_capi`/`cert_capi` signature change to surface the scalar margin `m_σ` (today only a boolean is used). Mirror into `safety_layer.maneuver_decide` (renderer + library diverge today). Solves thrash (seed-25 switches=101 → geometry-driven O(genuine cert-failure events)) + re-enables `EGO_FOVCAP` (~10 reaches). Frame as **"bounded, geometry-driven switching" NOT liveness** (the theorem switches≤empty-interval-events is near-tautological; its content is that switches are geometry- not noise-driven). Position explicitly vs MADER (commit-until-infeasible) + T-MPC (de Groot/Alonso-Mora cost-consistency, arXiv:2401.06021) — both need a baseline arm in the eval.

**⚠️ CCF EMPIRICALLY KILLED (2026-06-30, same day):** implemented CCF v1 in render_3d_video.py (EGO_CCF/EGO_CCF_WARP gates, default now OFF) and it is a NET NEGATIVE — froze 2/5 natural seeds (reached=False, over-commit can't release in flickering clutter), switches UP on several. Decisive instrumentation (classify switches by type + jerk/reversal cost, 10 natural seeds): the L/R-flip CCF targets is ~**0.7 per episode** (7 flips in 10 eps) = a NON-PROBLEM. The real switch churn is straight↔around (40%, FUNCTIONAL return-to-goal progress — suppressing it is what froze the drone) + over/climb/hold (57%, vertical/hold, which CCF doesn't touch). Verdict: **the thrash is not worth fixing; CCF solves a non-problem.** Do NOT re-attempt CCF without new evidence the L/R flip matters. The strongest EMPIRICALLY-SUPPORTED result is the predict ablation: KF prediction ~**2x pedestrian clearance** (ON 1.2-1.6m vs OFF 0.4-0.9m, EGO_PREDICT=0 ablation) under the forward FOV cone. Also note: mover see-too-late COLLISIONS are near-impossible to elicit (adversarial fast crosser EGO_ADV_CROSSER=1 still 0 collisions; failure mode is tighter clearance or a freeze, not a crash) — matches the audit's "latent" finding + Bouraine-Fraichard.

**✅ NEW HEADLINE (2026-06-30): age-conditional conformal coverage.** After CCF died, pivoted to making `q_conformal` honest. Extended `metaurban/conformal_calibrate.py` (added `age=trk.n` to `residuals_for_track`, AGE_BUCKETS, `age_coverage()`, the per-age table; calib over 20 harvested `out/conformal/traj_seed*.npz`). Ties perfectly to FOV: limited cone → movers constantly ENTER fresh → fresh tracks are exactly the under-covered + safety-critical regime. This is the new contribution (honest, OFFLINE = no closed-loop fragility, builds on existing infra). Output in `out/conformal/calib.json` `age_coverage` field.
