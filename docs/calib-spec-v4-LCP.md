# 第四代标定规范草案:LCP 权重优化(2026-07-08)

> 文献基座:Cleaveland et al., AAAI 2024 (arXiv:2304.01075) —— 深研 3-0 票验证。
> 关键洞察:**λ-SHAPE-H 已是 LCP 家族实例** —— 我们的 per-flight sup 分数 `max_t (e_t/shape(Δ_t))` 恰是论文的 `R := max(α_1 R_1, …, α_T R_T)`,其中 α_t = 1/shape(Δ_t)。区别仅在:我们的 α 来自包络拟合(q90 逐Δ + Theil-Sen 仿射,2 参数);论文的 α 在**额外数据集上优化**(MILCP→LCP 松弛)以最小化区域体积(22 点自由权重)。升级 = 换 α 的来源,分数结构、单秩、per-flight 语义、distribution-free 覆盖全部不动。

## 配方
1. **设计域三分**(designC 按场景不相交切 A_shape/A_opt,B8 为新校准折):
   - A_shape:初始 α⁰_t = 1/q_t^{(1−δ)}(逐 Δ 分位数归一 —— 每步超越贡献均衡,LCP 最优的已知良好近似);
   - A_opt(held-out):优化 α(坐标下降/或直接用 α⁰,消融对比 LCP 精解的边际);
   - 优化目标:min Σ_t (q̂(α)/α_t)(部署半径总面积),q̂(α) = A_opt 上的 (1−δ) 分位 sup。
2. **冻结 α → B8 新折单秩 λ̂ → T8 验证**(θ6;B7/T7 已被 λ-SHAPE 烧掉)。
3. **部署**:r_t = λ̂/α_t 为 22 点半径曲线 → 进 C++ 仿射接口的两种路径:
   a. 仿射上包络(损失部分收益,零接口改动);
   b. **两段式包络**(近窗/远窗各一条仿射,cert 每圆柱两次调用 ≈14μs)—— 需 certify_horizontal 支持 t_lo 或等效平移技巧(工程项,待核)。
4. 臂结构沿用 λ-SHAPE-H(mature 乘性/young 加性钉 VCAP/static 平),仅 mature 臂换 α 曲线。

## 预期收益
文献:消 union-bound 保守 → "much tighter bounds"(Tumu et al. 引用)。我们侧:ped 管在中段 Δ 的过覆盖(TEST 1.000 @0.05 = 明显松)是收紧空间;直接对应剩余 ~10pp 干净率中的管宽部分。

## 红线
- α 优化集与校准折严格不相交(A_opt 摸过的数据不得进秩);
- feasibility 驱动调 α/δ = 结果购物,禁(CP-SIPP 教训);
- 若两段式包络工程不通,仿射包络兜底(收益打折但语义完好)。
