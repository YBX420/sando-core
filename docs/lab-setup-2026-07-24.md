# 物理室内实验室 setup 思考(2026-07-24)

> 对象:真机、室内飞行场。仿真面的实验矩阵另见 `docs/experiment-setup-2026-07-24.md`。
> 结论先行:**积木大半已有**(PX4 offboard 桥 / ROS2 ego_node / D435i 管线 / 检测+KF 面 /
> native SANDO 完整 ROS2 工作区),缺的主要是三样:动捕→EKF2 的定位链、
> velocity-feedforward 执行链、以及一套按里程碑走的安全规程。

## 0. 真机要证明什么(先想清楚,再动硬件)

真机不是仿真的放大版。统计主张(conformal 覆盖、final100)**留在仿真**;真机只做三件事:

1. **工程存在性**:感知→KF→决策→证书→执行整条栈在真机算力+真实延迟下闭环跑通;
2. **flown==certified 在真实动力学下守住**:跟踪误差 δ_track 的真机版(HCT-D 方法直接搬,
   数据源换成动捕 vs 承诺样条);
3. **headline 成片**:认证绕行真横穿者、与 native/裸 EGO 的配对 AB 实拍。

每个架次都是时间、电池和炸机风险——真机实验=**存在性证明+少量配对 AB**,不是刷统计。

## 1. 设计主轴:感知三档 = 仿真三臂的真机镜像

动捕系统天然给出一个阶梯,和仿真的估计器税阶梯一一对应:

| 真机档 | 障碍信息来源 | 对应仿真臂 |
|---|---|---|
| A 全知 | 动捕直喂 mover 位置+速度 | ORACLE_THIN |
| B 半知 | 动捕位置 + 我们的 KF 估速度 | GT_XY |
| C 生产 | 机载 D435i 锥 + 检测/跟踪 + KF | KF 生产臂 |

同一场景、同一账本口径跑三档 → **估计器税阶梯在真机上直接复刻**。顺序 A→B→C,
每档单独验收,C 档不通不影响 A/B 的结论成立。

## 2. 硬件清单(最小可行配,留待填项)

- **机体**:330mm 级碳架四旋翼 + PX4(Pixhawk 6C mini 类),载荷预算 ≥600g;
  Crazyflie 太小载不动 D435i,不选。
- **机载计算**:Jetson Orin NX(或同级)。证书本身近乎免费(横向 0.04ms、竖直 76ms bug
  已修、EGO replan ~1ms),真瓶颈是检测器——nuScenes 面 YOLO+ByteTrack@12Hz 的数字
  说明 Orin 档够用。
- **传感**:D435i(坑已在仿真趟过:外参从输入构造、相机朝 heading 不朝 yaw、
  体素降采样 D435I_VOX=0.25、只喂预测圈)。
- **定位**:室内无 GPS → 动捕 marker + **mocap→PX4 EKF2 vision_pose 融合**(新积木,
  SITL 的教训——等满 health 再 arm、arm 重试——原样适用)。
- **动态障碍**:遥控小车/扫地机器人顶泡沫假人柱(高度≈行人,轻、撞了无伤);
  横穿者对时 = 遥控脚本掐点(contest 律的真机版)。真人只在最后里程碑、低速档、
  且规程允许时才上。
- **静态障碍**:纸箱堆/软垫圆柱(贴我们证书的圆柱假设)。
- **场地(待填)**:动捕覆盖的飞行笼,尺寸 __ × __ × __ m。**场地尺寸决定 vmax 封顶**:
  20m 长的场飞不出 8m/s 的故事,速度主张按场地缩放,别把仿真的速度数字往真机上许。

## 3. 软件接线(什么现成、什么要建)

**现成**:
- `metaurban/px4_bridge.py`(MAVSDK offboard,health-wait/arm-retry/电池教训全在);
- `ros/ego_node.py` + `ops/ego_mighty.sh`(ROS2 Humble,已能整机接管 Gazebo 栈,
  订 goal、发轨迹——真机上只是把话题源从 Gazebo 换成动捕/D435i);
- 检测→跟踪→KF 面(nuscenes/ 四件套回迁);
- native SANDO 基线 = `sando_ws` 完整 ROS2 工作区(另一台机器),真机 AB 对手现成。

**要建(按优先级)**:
1. **velocity/trajectory feed-forward offboard**——SITL 实测 position-only 慢 10 倍
   (54.6s vs 5.4s)。不修这个,"比 native 快"的主张在真机上直接被执行链吃掉,
   而且对 ours/native 都慢≠公平借口(两边同链公平,但绝对速度没法看)。**真机第一刀**。
2. mocap→EKF2 融合与外参/时钟对齐(动捕丢帧/延迟要实测入账)。
3. mover 话题适配:动捕 rigid-body → 我们 KF 的观测口(A/B 档);D435i 检测 →同口(C 档)。
4. 账本真机版:**五件套 = rosbag(全话题)+ 动捕导出 + explain jsonl + 账本 + 外机位实拍**。
   证明纪律的真机版=实拍成片,双机位(俯瞰+侧面)。

## 4. 证书与 conformal 的真机诚实口径

- **λ 不可迁移**(这是同一个坑的第三次出现:final100→guide 臂、仿真→真机):真机残差
  分布≠仿真,仿真标定的管子到真机**不声称覆盖**。真机臂默认 **THIN 明文薄壁**,
  只报实测净空——这条路径本来就是合法且现成的。
- 若想要真机覆盖主张:动捕录 mover 真轨迹→离线收残差→小 n 标定。但 RUNG-3 教训在前:
  几十个场景撑不起 ε=0.05,最多 ε=0.1 粗档,或干脆不主张。建议:第一轮不主张。
- **急停距离实测反喂 d_safe**:L0 里程碑实测真机急停/让行距离,d_safe 和让行地板
  (0.7s 物理地板)用真机数字重申,不沿用仿真拍脑袋值。
- 新增诚实边界(真机特有,论文/汇报要写):动捕延迟与丢帧、D435i 室内红外/反光干扰、
  下洗气流吹动轻质假人(假人要配重)、电池电压下垂改变动力学。

## 5. 里程碑阶梯(每步有验收判据,不跳级)

- **L0 基建**:mocap→EKF2 悬停+方波跟踪;geofence+kill switch 演练;急停距离实测。
  验收=位置跟踪 RMS ≤ __ cm、急停距离表(喂 §4)。
- **L1 静态认证绕行**:纸箱走廊,A 档。验收=到达 ∧ 0 碰 ∧ flown-certified 净空≥0
  (账本口径=机体净空,与仿真 9d974de 一致)。
- **L2 动态横穿**:遥控小车掐点横穿,A→B 档。验收=认证绕行成片 + 让行地板复现
  + δ_track 真机重标完成。
- **L3 生产臂**:D435i 锥 + 检测 + KF(C 档),同 L2 场景。验收=三档同场景税阶梯表。
- **L4 配对 AB**:vs native SANDO、vs 裸 EGO,同执行链同场地同场景。
  验收=配对表 + 双机位成片。
- (远期)真人低速档、多 mover、遮挡广告牌真机版。

## 6. 安全规程(硬性,先于一切飞行)

- 笼/网内飞行;**人不进笼**(真人实验前全程假人,真人上场需单独评估+低速档)。
- vmax 按场地封顶;PX4 geofence + 断链 failsafe(offboard 断→hold→land)双重兜底。
- 急停双人制:飞手持遥控随时接管,第二人持 kill。每架次前 checklist:
  桨/电池电压/动捕锁定/geofence 生效/录制已开。
- 电池纪律:SITL 的电池教训真机版=真的会掉下来;设低压强制降落阈值,不飞边缘电量。
- HOLD 兜底在真机=悬停,悬停也要证(hold_cert 收据照发);无证暴露照记 U,账本口径不放水。

## 7. 待塔菲大人确认的关键问题(决定采购和顺序)

1. 实验室是否已有动捕(型号/覆盖范围/频率)?还是要走 UWB/视觉里程计路线(那样 A/B 档
   的"真值"质量都要打折,阶梯设计要改)?
2. 场地尺寸与可用时段(决定 vmax、走廊长度、场景库怎么缩)。
3. 机体是现有的还是新购?机载计算平台定了吗?
4. 遥控小车/假人道具能否采购;真人实验在学校安全规程下是否可行。
5. native SANDO 真机臂跑不跑(L4 的 AB 对手;不跑就只 vs 裸 EGO)。

## 8. 与仿真面的关系(一句话)

仿真面负责统计与迭代(0-hold 战役、final100),真机面负责**执行链与感知的真实性**;
真机上不追 0-hold 北极星——先把"飞的=认证的"在真实动力学下守住,再谈快。
