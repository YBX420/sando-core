# 物理室内实验室 setup 思考(2026-07-24,v2:按已定条件改写)

> 已定条件(塔菲大人 07-24 拍板):机体已有;机载计算 = NUC;**没有动捕**;
> 用视觉 fiducial tag(AprilTag/ArUco 类)获取物体 xy 真值;**先不做真人**,全程假人/道具;室内。
> 仿真面的实验矩阵另见 `docs/experiment-setup-2026-07-24.md`。

## 0. 真机要证明什么(不变)

统计主张(conformal 覆盖、final100)**留在仿真**;真机只做三件事:

1. **工程存在性**:感知→KF→决策→证书→执行整条栈在 NUC 算力+真实延迟下闭环跑通;
2. **flown==certified 在真实动力学下守住**:δ_track 真机重标(HCT-D 方法直接搬,
   数据源换成 tag 真值 vs 承诺样条);
3. **headline 成片**:认证绕行真横穿道具、与 native/裸 EGO 的配对 AB 实拍。

每架次都是时间/电池/炸机风险——真机=**存在性证明+少量配对 AB**,不是刷统计。

## 1. 核心方案:顶视 tag = 穷人版动捕

一套**场地端固定顶视相机 + 大尺寸 AprilTag**,同时干两件事:

- **mover 真值**:遥控小车/假人柱顶面贴大 tag(≥20cm,tag36h11),顶视相机 30-60Hz
  解出 xy+yaw。小车 ~1m/s,cm 级精度足够账本用。
- **无人机定位(路线一,推荐先走)**:机顶贴 tag(或 tag bundle 防倾角/桨遮挡),
  同一套相机解 xy+yaw → 以 external vision 喂 PX4 EKF2(vision_pose);
  z 不靠 tag(尺度噪声大),用机载激光测距/气压。
- **路线二(备选)**:机载下视相机 + 地面 tag 阵自定位。不依赖外部相机,但吃 NUC
  算力和一个相机口(与前视 D435i 并存)。路线一延迟/丢检实测不过关再切。

**裁判与被试分离(纪律)**:tag 真值在 C 档(机载感知)飞行时**只做裁判**(账本/净空/
δ_track),绝不喂给算法;A/B 档才把它作为观测源。同一套真值,两种角色,账本里分列。

**tag 管线的三项硬指标(L0 先测,先于一切飞行)**:
- 静态精度:tag 摆已知位置(卷尺/激光尺)对表,目标 ≤3-5cm;
- 动态精度+运动模糊:小车已知速度跑直线,看解算抖动(全局快门/短曝光优先;
  滚动快门相机要实测能不能用);
- **延迟与时钟**:闪灯/LED 触发法实测相机→解算→话题全链延迟;全系统统一 ROS time,
  tag 观测带时间戳做延迟补偿。这三个数字进账本 provenance,以后每次实验引用。

## 2. 感知三档 = 仿真三臂的真机镜像(tag 版)

| 真机档 | 障碍信息来源 | 对应仿真臂 | 诚实备注 |
|---|---|---|---|
| A 场地真值 | tag xy 差分+平滑 → 位置+速度直喂 | ORACLE_THIN | tag 本身 cm 级+差分速度噪声,**≠仿真的完美全知**,账本写明真值误差预算 |
| B 半知 | tag xy + 我们 KF 估速度 | GT_XY | 正好复刻"精确位置+估计速度" |
| C 生产 | 机载 D435i 锥 + 检测/跟踪 + KF | KF 生产臂 | tag 只当裁判 |

顺序 A→B→C,每档单独验收;三档同场景 → 估计器税阶梯真机复刻。

## 3. 硬件清单(按已定条件收敛)

- **机体**:已有。需确认:载荷余量(NUC+D435i+云台/支架)、PX4 版本、offboard 接口。
- **机载计算**:NUC。证书近乎免费(横向 0.04ms、EGO replan ~1ms),检测器 YOLO 在
  NUC 的 CPU/核显上帧率要实测——nuScenes 面的 12Hz 是有 GPU 的数字;NUC 跑不动就
  降输入分辨率/换 nano 档模型,或 C 档检测频率降到 6-8Hz(KF coast 补,正好是
  update-or-coast 定律的真机版)。**L0 加一项:NUC 上全栈 tick 延迟预算实测**。
- **场地端**:1-2 个顶视相机(优先全局快门 USB/GigE;高处广角覆盖场地,棋盘标定内外参)
  + 一台地面站电脑跑 tag 解算与录制(不占 NUC 算力)。
- **传感**:D435i(坑已趟过:外参从输入构造、朝 heading、体素 0.25、只喂预测圈)。
- **动态障碍**:遥控小车(或扫地机器人)顶泡沫假人柱,柱顶平面贴 tag;假人配重防下洗
  气流吹动。横穿者对时=遥控脚本掐点(contest 律真机版)。**不上真人。**
- **静态障碍**:纸箱堆/软垫圆柱(贴证书的圆柱假设),顶面也贴 tag(静态真值+一次性标定)。
- **场地(待填)**:__ × __ × __ m。尺寸决定 vmax 封顶和相机覆盖方案;速度主张按场地缩放。

## 4. 软件接线(现成 vs 要建)

**现成**:`px4_bridge.py`(MAVSDK offboard+SITL 全部教训)/ `ros/ego_node.py`(ROS2 整机
接管已验证,话题源换成 tag/D435i 即真机)/ 检测→跟踪→KF 面(nuscenes/ 回迁)/
native SANDO 完整 ROS2 工作区(AB 对手)。

**要建(按优先级)**:
1. **velocity/trajectory 前馈 offboard**——SITL 实测 position-only 慢 10 倍(54.6s vs
   5.4s),不修则"快"的主张被执行链吃掉。**真机第一刀。**
2. **tag 管线**:场地相机标定 + AprilTag 解算节点 + 延迟补偿 + rigid-body 命名
   (mover1/mover2/drone),发 ROS 话题;三项硬指标验收(§1)。
3. **tag→EKF2 融合**(路线一):vision_pose 喂 PX4;丢检时 EKF2 惯性桥接,
   丢检超时的 failsafe 演练(悬停→降落)。
4. mover 话题适配:tag 观测 → KF 观测口(A/B 档);D435i 检测 → 同口(C 档)。
5. 账本真机版:**五件套 = rosbag(全话题)+ tag 真值导出 + explain jsonl + 账本 +
   外机位实拍**(双机位:顶视相机自带俯瞰,补一个侧面机位)。

## 5. 证书与 conformal 的真机诚实口径

- **λ 不可迁移**(第三次同坑):仿真标定的管子到真机不声称覆盖;真机臂默认
  **THIN 明文薄壁**,只报实测净空。第一轮不做真机覆盖主张。
- **急停距离实测反喂 d_safe**:L0 实测真机急停/让行距离,d_safe 与让行地板用真机数字重申。
- 真机特有诚实边界(汇报要写):tag 真值误差预算(静/动/延迟三数字)、顶视相机
  丢检与遮挡、D435i 室内红外/反光、下洗吹动道具(已配重)、电池电压下垂改动力学、
  NUC 检测帧率低于仿真感知节拍时的 coast 占比。

## 6. 里程碑阶梯(每步有验收,不跳级)

- **L0 基建**:tag 管线三指标验收(§1)→ tag→EKF2 悬停+方波跟踪 → geofence+kill
  演练 → 急停距离实测 → NUC 全栈 tick 延迟预算。
  验收=位置跟踪 RMS ≤ __ cm、三指标表、急停距离表。
- **L1 静态认证绕行**:纸箱走廊,A 档。验收=到达 ∧ 0 碰 ∧ flown-certified 净空≥0
  (机体净空口径,与仿真 9d974de 一致)。
- **L2 动态横穿**:遥控小车掐点横穿,A→B 档。验收=认证绕行成片 + 让行地板复现 +
  δ_track 真机重标完成。
- **L3 生产臂**:D435i 锥+检测+KF(C 档),同 L2 场景,tag 只当裁判。
  验收=三档同场景税阶梯表。
- **L4 配对 AB**:vs native SANDO、vs 裸 EGO,同执行链同场地同场景。
  验收=配对表+双机位成片。
- (远期,均暂不做)真人低速档、多 mover 群、遮挡广告牌真机版。

## 7. 安全规程(硬性,先于一切飞行)

- 笼/网内飞行;**人不进笼**(本阶段无真人实验,操作全在网外)。
- vmax 按场地封顶;PX4 geofence + 断链 failsafe(offboard 断→hold→land)+
  **tag 丢检超时 failsafe**(外部定位路线特有)三重兜底。
- 急停双人制:飞手持遥控随时接管,第二人持 kill。架次前 checklist:桨/电池电压/
  tag 视野无遮挡/geofence 生效/录制已开。
- 电池纪律:低压强制降落阈值,不飞边缘电量。
- HOLD 兜底在真机=悬停,悬停也要证(hold_cert 收据照发);无证暴露照记 U,口径不放水。

## 8. 剩余待确认(比 v1 少多了)

1. 场地尺寸与顶视相机安装条件(层高、能否吊装)→ 定相机数量与 tag 尺寸;
2. 机体载荷余量与 PX4 固件版本(定 D435i+支架怎么挂);
3. NUC 具体型号(有无核显/独显)→ 定检测器档位;
4. native SANDO 真机臂跑不跑(L4 的 AB 对手;不跑则只 vs 裸 EGO)。

## 9. 与仿真面的关系(一句话)

仿真面负责统计与迭代(0-hold 战役、final100),真机面负责**执行链与感知的真实性**;
真机不追 0-hold 北极星——先把"飞的=认证的"在真实动力学下守住,再谈快。
