## 1. 这个项目在做什么

**场景**：一架小型无人机在有行人、车辆的街道上空低空飞行，要从起点飞到终点。行人和车会动，而且无人机的传感器是"真实"的：只有 45° 的前向视野、会被遮挡、会漏检、测量有噪声、也不知道每个目标的身份。

**目标**：又快又安全地到达。项目的头号考核指标叫**"干净抵达"**，必须同时满足三个条件：

1. 到达终点；
2. 全程零碰撞；
3. 全程没有触发过任何一次"紧急规避"（即从头到尾都在有安全证明的状态下飞）。

**核心思路，一句话**：先**预测**每个行人/车接下来一秒内会到哪里，让规划器**提前绕开这些"未来的位置"**；在真正执行之前，再用数学方法对规划出的轨迹做一次**严格的安全证明**——证明"接下来这一小段飞行，在每一个时刻都不会进入任何目标的危险范围"。证明通过才飞；通不过就换更保守的动作再证；实在全都证不过，才做没有保证的紧急规避（这种情况单独记账，算"不干净"）。

**和一般避障系统的区别**：一般系统是"规划器尽量绕，撞不撞看运气"；本系统在规划器外面加了一道**独立的、可证明的安全关卡**，并且给出一个可以写成定理的总保证（见第 3 节）：

> **在统计前提成立时，一整次飞行中"在已认证状态下发生碰撞"的概率 ≤ 5%。**
> （实测中已认证状态下的碰撞为 0；所有残余碰撞都发生在传感器物理上看不见的方向，且经"全知对照"证实全知也躲不掉，详见第 6 节。）

## 2. 系统怎么工作：六步流水线

整个系统每 0.3 秒跑一轮下面的循环（"一拍"）：

```
感知 → 跟踪与预测 → 加上预测误差余量 → 规划 → 安全证明 → 决策执行
```

### 第 1 步：感知（模拟真实传感器）

无人机不直接读仿真器的"上帝视角"数据，而是通过一个模拟真实传感器的前端（代码 `perception.py`，规格按 Intel D435i 深度相机）：

- 只有前向 45° 视野锥，锥外一律看不见；
- 有硬遮挡：被建筑/其他物体挡住就看不见；
- 有漏检和位置噪声；
- **不知道目标身份**：这一帧看到的点和上一帧看到的点是不是同一个人，要靠最近邻匹配自己猜。

这保证了所有实验结论是在"真实感知"条件下取得的，不是全知作弊。（评测时也可以显式切到全知模式做对照，用于区分"感知问题"和"算法问题"。）

### 第 2 步：跟踪与预测

每个被看到的目标分配一个**卡尔曼滤波器**（代码 `kf_tracker.py`），用"匀加速"运动模型持续估计它的位置、速度、加速度，并外推出未来约 1 秒内的预测位置曲线：

```
c(t) = c0 + v·t + ½·a·t²
```

两个重要的诚实规则（都是实验教训，见第 5 节）：

- **刚出现的目标不可全信**：观测次数太少时速度估计不可靠，这类"新目标"按最坏情况处理，但**限时**——连续 2 拍还没确认就丢弃，不许它无限膨胀；
- **只有"成熟"目标（连续观测 ≥ 4 次）的预测才被下游的精细功能采信**。

### 第 3 步：预测误差余量（统计标定）

预测一定会错。关键问题是：**错多少？** 我们的做法是——不做任何分布假设，直接**用数据量出来**：

1. 在标定阶段，跑几百集仿真，收集几万条"预测 vs. 事后真实位置"的记录，每条算出误差 e（预测了 Δ 秒后，真实位置离预测位置多少米）；
2. 给余量定一个随时间变宽的直线形状：

   ```
   余量(Δ) = b + v·Δ        （截距 b + 斜率 v）
   ```

   行人和车辆分开标，"新目标"和"成熟目标"分开标（误差规律完全不同）；
3. 在标定数据上选出最小的缩放系数，使得 95% 的记录误差都被余量盖住。

**它保证什么**：只要新场景和标定场景"统计上同类"（专业名词叫可交换，直白说就是同一个世界、同一套传感器规律，只是换了随机种子），那么新场景里**预测误差有 95% 的把握不超过余量**。这是一个不依赖任何分布假设的保证。

**它怎么用**：第 4、5 步里，每个目标的"危险范围"半径都按预测时长加上这个余量：

```
R(Δ) = [r_目标 + r_机体 + d_安全]（确定性几何） + [b + v·Δ]（预测误差余量）
```

预测越远，余量越大，"危险范围"越宽——这是诚实的代价。

**标定方法迭代了三代**（细节见附录 A）：一代是全体记录混在一起取一个分位数（粗）；二代按类别、成熟度、预测时长分组细标（准，但组太多后每组数据不够，出过一系列统计事故）；三代（**现役**）把"形状"（截距和斜率的相对比例）冻结下来，只用新数据估一个总缩放系数——估计误差只会让余量变宽、绝不会让覆盖率变假。三代标定让行人余量瘦了 33%，车辆"新目标"余量截距从 14.46 米（离谱）修到 0.71 米，且在保留测试集上覆盖率 0.969（目标 0.95）合格。

### 第 4 步：规划（让规划器绕开"未来"）

规划器用的是浙江大学开源的 EGO-Planner（已剥离 ROS，编译成独立库，代码 `ego/` + `ego_bridge.py`）。我们**不改规划器内部**，只改喂给它的障碍信息：把每个目标**未来位置的预测**（带余量）转成占据点云喂进去，规划器就会自然规划出一条**绕开"目标即将到达的地方"**的轨迹，而不是等目标到了跟前再躲。

其中一个有效的技巧：把目标摆在"相对运动最近点"时刻的预测位置上（即它和无人机距离将会最近的那个时刻），规划器就学会了从预测的空隙中穿过，干净抵达率 +4.1 个百分点。前提就是上面说的"只信成熟目标"——拿不准的预测宁可不用，错误的预测比没有预测更危险（实验中真撞过一次）。

### 第 5 步：安全证明（核心部件）

规划器给出轨迹后，**独立的证明器**（C++ 实现，代码 `cpp/include/sando_cpp/bernstein_cert.hpp`）要回答：

> **"未来这段时间内，无人机与每个目标的距离，是否在每一个时刻都大于危险半径 R？"**

**原理（一段话说清）**：无人机轨迹是多项式，目标预测位置也是多项式，所以"两者距离的平方减去 R²"也是一个关于时间的多项式 f(t)。把 f(t) 改写成一种数学上等价的系数表示（Bernstein 形式），它有个极好的性质：**函数在整个区间上的值，永远不超过最大的那个系数**。于是：

```
所有系数 ≤ 0  ⟹  f(t) ≤ 0 在整段时间成立  ⟹  整段时间距离 ≥ R
```

一次代数检查，就覆盖了**区间内的全部无穷多个时刻**——不是抽查几个时间点（抽查有漏网风险，这正是很多现有系统的隐患）。如果系数有正的但实际是安全的，就把时间段对半细分再检查，越分越贴近真实曲线（最多 16 层，通常远用不到）。

**三个可靠性设计**：

- **连续时间、零采样漏洞**：如上，结论对区间内每个时刻成立；
- **浮点数不说谎**：所有运算用"往不利方向取整"的区间算术（每步各往外挪一个最小浮点单位），浮点误差只可能让结论更保守，绝不可能把危险误判成安全；
- **只判不改**：证明器只输出"通过/不通过 + 裕度"，绝不修改轨迹。职责单一，才谈得上可信。

**速度**：单次检查约 7 微秒，一拍内把几十个候选轨迹对全部目标都证一遍毫无压力。另外，证明器与具体规划器**解耦**：同一套数学既能证 EGO 的三次样条，也能证自研规划器的五次多项式（这是支撑性质，不是卖点主线）。

### 第 6 步：决策与执行

每 0.3 秒（代码 `safety_layer.py` 的统一决策函数）：

1. 规划器给出一条奔终点的轨迹 → 全部目标跑一遍安全证明 → **全过就直接飞**，本拍结束；
2. 证不过 → 生成一批**候选动作**：方向（原方向/左偏/右偏/爬升）× 速度档（全速到 0.15 倍"爬行挡"），每个候选都独立跑证明，在**全部证得过**的候选里选**进度最快**的那个执行；
3. 有"粘性"机制：上一拍的选择在本拍有优先权，避免每拍换主意来回抖；另有"逃逸压力"信号：当最近威胁的净空持续收缩时，提前把逃逸类候选排到队伍最前（只改排序偏好，每个候选仍必须通过证明）；
4. 候选全军覆没 → **紧急规避**：朝远离威胁的方向逃。**这一下没有任何证明保护**，所以单独记账，发生一次这集就不算"干净"。

两个与"时间"有关的关键设计（合计是整个调优战役里单笔收益最大的改动，干净抵达率 +13.9 个百分点）：

- **速度换证明窗**：证明需要覆盖的时间窗 = 一拍时长 + 当前速度下的刹停时间。飞得慢 → 刹停快 → 窗短 → 预测误差余量小 → 更容易证过。于是"降速"成了换取"可证明性"的连续杠杆；
- **爬行挡**：候选速度网格里加一个 0.15 倍速的最低档。全速证不过时还能慢慢挪，而不是停在原地变成活靶。

## 3. 总保证：两半拼成一个定理

第 2 节第 3 步的统计余量和第 5 步的几何证明，各自只保证一半：

- 统计半边："预测不会错得比余量更多"——95% 概率；
- 几何半边："只要预测没错出余量，就绝对不撞"——100% 确定。

两半拼起来（文档 `docs/composition-theorem.md`，2026-07-04 定版）：

> **定理（直白版）**：标定场景与测试场景统计上同类时，对一个新场景，
>
> **P(全程在已认证状态下飞行时发生碰撞) ≤ ε = 5%。**
>
> 紧急规避时段不在此保证内（单独计量、单独报告）。

**让定理落地的关键一招——"重新证明的节奏"**：如果余量要覆盖整整 0.85 秒的预测误差，95% 分位的余量高达 3.18 米——无人机在街道上根本没法动。但系统**每 0.3 秒就重新证明一次**，所以任何碰撞发生前的 0.4 秒内必然刚刚通过过一次证明；于是余量只需覆盖 0.4 秒内的预测误差：**3.18 米 → 1.02 米**，缩小 3 倍，系统才真正可用。这一步同时把统计的"可交换单元"从聚在一起的记录修正为整段场景，保留测试覆盖率从 0.890 提到 0.987。

**三本账，防止"证了一半冒充全证"**：

1. **已认证飞行**：上面的 ε 保证覆盖；
2. **沿用旧轨迹**（重规划偶尔失败时继续飞上一条已证轨迹）：频率可测量，按测得频率单独摊账；
3. **紧急规避**：无保证，按暴露时长如实报告。（这是结构性的：凡是能证明安全的动作都不会走到这一步。）

## 4. 实验结果

### 4.1 先说清楚：三个"测量面"

同一套算法在三种环境下测，**数字不能互相混用**，每个数字都必须标明来自哪个面：

| 测量面 | 是什么 | 用途 |
|---|---|---|
| 快速回放面 | 在预先录制的真实群体轨迹上离线重放，几百集/波，几十分钟出结果 | 日常迭代、标定、消融 |
| 真引擎面 | MetaUrban 完整物理引擎在线跑 | 行为结论的最终复核 |
| 3D 渲染面 | 带画面的完整仿真，出视频 | 给人看的演示与取证 |

**已知坑**：3D 渲染面目前只读一代标定文件，二、三代标定和部分新开关在渲染面**不生效**——所以渲染面数字与评测面数字不可比，调参前必须先分清作用面。

### 4.2 主结果：干净抵达率（快速回放面，每档 345 集）

| 配置 | 干净抵达 | 紧急规避次数 | 说明 |
|---|---|---|---|
| 战役起点（一代标定） | 51.0% | 1290 | 出发点 |
| **现役最优栈（V11）** | **68.4%** | **531** | 到达 95.1%，**0 碰撞** |
| 视野内全知（对照） | 78.3% | 260 | 感知不变、预测全对的天花板 |
| 360° 全知（对照） | 69.3% | 178 | 见下方说明 |

三点解读：

- 现役最优栈把"多余的紧急规避"压掉了 59%（1290 → 531），同时保持全程零碰撞——这正是"干净抵达"哲学：安全不靠疯狂急刹；
- **天花板以 78.3% 为准**：它保持同样的 45° 视野、只把预测换成完美预测，度量的是"预测和决策还有多少可挖"。剩余差距（68.4% → 78.3%）主要是成熟行人在 3–4 米迎面几何下诚实余量的代价；
- **有趣的"不知者无罪"效应**：360° 全知反而比视野内全知更多急刹——因为它看得见侧后方来车，会提前躲。这说明"更多信息"不等于"更平顺"，是论文的讨论点。

### 4.3 真引擎面复核

- 全栈（V7）在真引擎上干净抵达 64.3%，与快速回放面的 64.3%（同口径配置）**精确互证**——回放面结论可信；
- **20 集验收**：全栈共 7 次碰撞，其中 **6 次全知对照也在同一集死**（出生点旁车碾压、高速横穿等，物理上无解），真正归咎于感知栈的只有 1 次；排除物理无解的集后干净抵达 9/14 = 64.3%；
- 版本阶梯回归（每版本 10 集、场景序列固定）："新目标限时"改动在真引擎复现了回放面的收益（急刹 −36% vs. 回放面 −29%），证明改进不是回放面的过拟合产物。

### 4.4 与原生规划器的对比（核心卖点）

同样的感知、同样的场景，"我们的完整系统" vs. "原生 EGO-Planner 直接飞"：

| 指标 | 我们 | 原生 EGO |
|---|---|---|
| 碰撞（真实感知+动态，304 集） | 4/304 = 1.3% ≤ ε | 18/304 = 5.9% |
| 碰撞（全知感知各臂，1216 集总账） | **全臂 0 碰撞 0 近失** | — |
| 最小碰撞时间余量（反应裕度） | 0.59 s | 0.22 s |
| 速度代价 | 比原生慢 5.7% | — |

即：**碰撞降到 1/4 以下、反应裕度 2.7 倍，代价只有 5.7% 的速度**。诚实项：按标准舒适性口径，"猛度"（加加速度）指标原生更优——我们的规避动作仍比原生猛，这是下一步架构工作的目标之一（见第 7 节）。另有 3D 渲染面的论文级对比：弯道新地图上**原生撞毁、我们以 0.83 米净空安全到达**（视频 `out/PROOF1_safety_curvemap.mp4`）。

### 4.5 强化学习验证臂（支撑性质）

把同一道安全关卡套在一个纯强化学习（PPO）策略外面，验证"这道关卡不挑规划器"：

- 关卡开/关对比：碰撞 6.75% vs. 14.25%（400 集，Fisher 检验 p = 0.0007），且开关卡**还提高**了到达率；
- 训练时把标定冻结进训练环境，最优版本碰撞 6.0% vs. 裸策略 16.25%；
- 结论：安全关卡对自研规划器、开源规划器、端到端学习策略**三类**都有效。（此线已归档，只作支撑，不再投入。）

### 4.6 平顺性战役（姿态）

问题：急刹时机体猛俯仰（倾角变化率 182°/s vs. 原生 122°/s），画面难看且危险。根因："悬停保持"的参考点是**冻结**的，6 m/s 的动量撞上一个不动的参考点自然猛。修法：把参考点换成"按最大减速度连续后退"的**刹车参考场**——物理上同样刹停，但参考轨迹不跳变。效果（3D 渲染面固定靶场）：姿态差距 59 → 12°/s、净空反而 1.30 → 1.95 米、还快 2.3 秒——**平顺不但免费，还倒贴安全和速度**（因为过冲导致的反复修正消失了）。配合逃逸压力提前触发，一个靶场上姿态与原生**完全打平**（144 vs. 144°/s）且净空 3 倍。

## 5. 一路上的关键改进（问题 → 原因 → 修法 → 效果）

这些是调优战役中被数据坐实的结构性胜利，每条都很直白：

1. **别把新数据当旧数据用**。决策代码假设观测是 0.3 秒前的（历史遗留），实际感知是当拍的——白白多算 0.3 秒的预测误差余量。改成 0.05 秒后：急刹 −74 次，干净抵达 +2.6 个百分点。
2. **没确认的目标不许无限膨胀**。一个只见过一两次的"疑似目标"丢失后还能滑行 8 拍，期间按最坏速度膨胀成一个巨大的禁飞圈。改成"2 拍内没确认就删"（多目标跟踪的教科书做法）：急刹 −350 次。
3. **同一份误差不许算两次**。新目标的标定误差记录本身已经包含了目标移动，部署时又叠加"最坏速度 × 时间"——等于运动误差收了两遍钱。拆掉后车辆新目标的余量截距从 14.46 米降到 0.70 米（此前一个环岛场景的禁飞圈直径 22.7 米，荒谬）：急刹 −195 次。
4. **速度换证明窗 + 爬行挡**（见第 2 节第 6 步）：干净抵达 +13.9 个百分点，整场战役单笔最大。
5. **预测"最近点"占据 + 只信成熟目标**：让规划器穿预测缝隙，+4.1 个百分点；全量采信新目标的版本真撞过（出生期速度低估被当真），限成熟目标后零碰撞且分数更高。
6. **刹车参考场救姿态**（见 4.6 节）。
7. **垂直逃逸的教训**（失败但重要）：被人群包围之后再想爬升逃逸，**永远证不过**——上升过程横向暴露在密集禁飞圈里。结论：想从头顶飞过，必须在包围圈闭合**之前**预防性触发，且必须先证明"降落走廊"也安全。方向性机动（横穿的目标从其身后过、同向的从头顶过、迎面的横向躲）已列为新决策层的候选生成规则，不做旧架构的补丁。

同样重要的是**被否决的方案**（各有铁证，防止将来重蹈覆辙）：子拍决策（不满足证明前提，撞过 1 次）、按滤波器方差自适应余量（长预测时方差爆炸）、车辆提前转正（物理上需要 3 个位移样本）、按"自知不确定度"过滤僵尸目标（滑行目标的不确定度膨胀恰好使其隐身）等。

## 6. 诚实边界（明确承认的局限）

项目哲学：**边界是主张的一部分**。物理上躲不掉的就承认躲不掉，用对照实验把"可修的"和"不可修的"分开，不假装没有边界。

1. **视野外快车 = 物理地板**。残余碰撞几乎全部是 45° 视野锥外、8.3 m/s 的侧后方快车（无人机才 3 m/s）。360° 全知对照**一次都没能减少**：1.9 秒预警 × 3 m/s 机动能力，对 8.3 m/s 的扫掠没有逃逸解。信息论审查确认只有两类机制能碰它（视野外证据如影子/第二传感器；或检测前就降速）——单传感器设定下这是**物理边界**，写入失效包络，不再追。
2. **紧急规避无保证**。这是结构性的（能证明的都不会走到这步），按暴露时长如实报告；评测显示规避与碰撞集中在同一批退化场景。
3. **保证是"分布内"的**。换场景生成器、换传感器规律，必须重新标定（标定协议已冻结存档）。标定必须与部署的节奏、感知分布一致——这是早期踩过的最大的坑（标定用 0.3 秒节奏、部署 0.1 秒，余量整体失真）。
4. **渲染演示面与评测面不同步**（见 4.1 节）：演示视频里的行为不能直接当评测证据；演示专用的"人群不停走"开关改变了人群统计规律，**禁止**用于任何安全声明。
5. **环境是平面的**。评测环境里高度自由度受限，使得"马路快车"成为致命项；真实 3D 产品可以爬升规避，论文需注脚。
6. **舒适性的"猛度"指标原生更优**（已如实报告），根治靠新架构而不是继续打补丁。

## 7. 正在进行的工作

### 7.1 新决策层：直接在"被证明安全的轨迹集合"里规划

**动机**：现在的决策层是"离散挑候选"（几十个方向×速度组合逐个证明），焊在连续的规划器上，接缝处天然会犹豫、抖动——一切平滑技巧都是在给一个近视的仲裁者打补丁。深度调研（104 个研究代理）也确认：根治 = **在认证集合内规划**，仲裁降为兜底。

**方案**（代码 `local_lattice.py`，设计文档 `docs/design-CPL-v3-cert-local-planner.md`）：每拍生成一批短轨迹基元，每条 = "先飞一小段 + 随后有限猛度刹停 + 停稳保持"，**整条（含刹停段）一次性证明**，在全部证得过的集合里按字典序（安全→进度→平顺）选优。好处：任何时刻系统都握着一条"已被证明能安全停下来"的完整退路（专业上叫递归可行性）。

**进展与代价**：

- 可靠性已锁死：10⁴ 场景**零假证明**；
- 但发现一笔沉重的"随时能刹停税"：要求整条刹停段都安全，意味着行人 1.75 米内连悬停都证不过（旧决策层可以 0.10 米贴身而过，17 倍差距，已在受控几何实验里量化到米）：到达率从 8/8 掉到 1/8；
- 三个设计级修法方向（已诊断指向，未实施）：① 刹停窗内不按"全向最坏速度"膨胀目标（消除双重保守）；② 把"完全刹停"弱化为"减速到可重新认证的状态"；③ 主动提前飞越（证得过的前进候选几乎都是爬升类，印证方向性机动的价值）。

**当前裁决**：新决策层暂不替换现役栈；渲染面与评测面现役仍是旧决策层最优栈。

### 7.2 第四代标定（已完成，待命）

直接在保留数据上优化**部署真正使用的**那条直线余量 (b, v)（而不是先拟合误差曲线再转换，消除表示错配）：行人/车辆余量全程比三代更瘦，覆盖率合格，急刹 531 → 452（标定单项史上最大红利）。但旧决策层的参数是按肥余量调的，直接换会小幅伤干净率——**裁决：不再给旧架构调参（补丁陷阱），四代标定与新决策层配套一次调成**。

### 7.3 待办清单（按优先级）

1. 新决策层的"刹停税"三修法，把到达率追平；
2. 标准舒适指标接入每类目标的真实半径；
3. 领域基线补齐（ORCA / DWA / MPC-CBF 对比）；
4. 统计封口：个别主张样本量不足（n=1 的姿态主张）、补"未触碰"确认折；
5. 渲染面接入二/三代标定（消除两面不同步）；
6. 真引擎面执行器滞后走查、个别场景超时排查。

## 8. 论文定位（一段话）

经双重文献查杀，两个卖点无近邻：① **端到端组合定理**——"无分布假设的统计保证 × 连续时间严格证明 × 对实际执行路径 × 分类条件"四者的合取（单项都有人做，合取是空白）；② **规划器×安全层的开放基准**——用严格连续时间证明作为与表示无关的违约裁判。副卖点："认证的优雅"（同等安全下更少急刹、更大反应裕度、姿态追平）。按类别分层单独当主卖点会死（方法论已被 Mondrian CP 占据），降级为诚实审计段。目标：RA-L 滚动投稿 + ICRA 2027。上游 EGO-Planner 的一个未定义行为 bug 已在移植中根修，可回报上游社区。
