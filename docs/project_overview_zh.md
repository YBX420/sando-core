## 1. 问题设定与系统总览

**任务**:一架小型无人机(机体半径 0.25 m,速度上限 3 m/s,加速度上限 6 m/s²)在有行人、
车辆的街道场景中从起点飞到终点。行人/车辆按真实群体轨迹运动(ORCA 人群或 MetaUrban
引擎),**不会为无人机让路**(最坏情况假设)。

**感知是"真实"的**:只有 45° 半角的前向视野锥、10 m 量程、有遮挡、有漏检、有噪声、
不知道目标身份(见第 2 节)。

**头号指标:干净抵达(clean arrival)**,一集同时满足三条才算:

1. 到达终点(判定:与终点的**水平**距离 < 0.8 m,不看高度);
2. 全程零碰撞(判定:无人机质心进入任一目标的身体圆柱;按 0.3 s 决策拍在飞行位置上采样,阈值 −10⁻⁶);
3. 全程零紧急干预(决策候选全灭后的兜底分支一次都没走:无保证的紧急规避 evade,
   以及可选的认证滑行 cret——后者虽通过证书但仍计入干预)。

**核心思路**:每 0.3 秒一拍,跑一遍六步流水线:

```
感知(传感器模型) → 跟踪预测(每目标一个卡尔曼滤波器)
→ 危险半径 = 几何项 + 统计标定出的预测误差余量(随预测时长变宽)
→ 规划(把预测占据喂给 EGO-Planner,让它绕开"未来")
→ 安全证明(对承诺轨迹整段做连续时间碰撞证书)
→ 决策执行(证过就飞;证不过在 方向×速度 候选里挑最快能证过的;全灭才紧急规避)
```

**与一般避障系统的区别**:规划器外面有一道**独立的、数学上严格的安全关卡**
(连续时间证书,覆盖时间窗内每一个时刻,浮点运算保守取整),
且统计半边(预测误差多大)与几何半边(误差不超余量就绝不撞)拼成一个端到端定理:
**在统计前提下,已认证飞行时段的单集碰撞概率 ≤ ε**(第 9 节)。

**三个测量面**(同一算法,三种评测环境,数字不可混用):

| 测量面 | 是什么 | 节拍 | 用途 |
|---|---|---|---|
| 回放面(`replay_core.py`) | 在录制好的真实群体轨迹上离线重放 | 0.3 s | 日常迭代/标定/消融 |
| 真引擎面(`ego_mu_bench.py`) | MetaUrban 完整物理引擎在线跑 | 0.3 s(引擎 3×0.1 s 子步) | 行为结论复核 |
| 渲染面(`render_3d_video.py`) | 带画面 + 真四旋翼动力学 | 决策 0.1 s / 动力学 0.02 s | 演示与取证 |

## 2. 感知前端:模拟真实传感器

代码:`metaurban/perception.py`(298 行,回放面/真引擎面/渲染面共用同一份)。
规格向 Intel D435i 深度相机看齐。每拍对世界里的每个目标(圆柱近似:中心 xy、半径 r、高 h、类别)做四道抽取:

**① 视野锥**:半角 45°(`PERCEPT_FOV_DEG`)、量程 10 m(`PERCEPT_RANGE`)。
量程按**最近表面距离**(质心距离减半径)判——大脚印物体(树冠 r=4.7 m)质心超出量程、
表面却近在眼前,按质心判会整场"看不见一棵挡路的树"(props_alley 场景曾因此在"已认证"状态下撞树,已修);
方位角仍按质心方向判,但无人机一旦进入目标脚印内(距离 ≤ 半径)则无条件可见。

**② 硬遮挡**:2D 射线判定,被别的圆柱挡住就看不见。同样为了诚实,
用**剪影可见性**:在目标朝向传感器的近弧上采 5 个点,任何一点在锥内且不被挡即可见
(深度相机看到的是整段可见弧,不是一条射线)。

**③ 漏检**:按表面距离的二次律 `P_miss(d) = min(0.95, 0.05 + 0.15·(d/10)²)`。

**④ 噪声**:位置噪声 `σ(d) = 0.05 + 0.01·d` 米;尺寸估计有 5% 的对数正态误差;
可选的类别翻转/杂波默认关。

**无身份关联**:检测不带"这是几号行人"的标签。用贪心最近邻把检测分给已有轨迹:
全局最近的 (轨迹, 检测) 对先配,门限 1.2 m;**刚出生的轨迹(只有 1 次检测,速度未知)门限放宽到
1.2 + 10·dt m**(不放宽的话 8 m/s 的车永远配不上,会无限生幽灵轨迹)。
配不上的检测生成新轨迹;配不上的轨迹"滑行"(coast,见第 3 节)。
交叉行人**可能**发生身份互换、遮挡**可能**把一个目标裂成两条轨迹——这正是要诚实保留的失效模式。

**轨迹生死**:没配上就滑行;滑行满 8 拍(`PERCEPT_TTL`)后仍配不上才删除。**例外一(重要改进)**:
未确认轨迹(更新次数 < 4)滑行上限只给 2 拍(`YOUNG_TTL=2`,现役栈开启;代码默认关)——一个只见过一两次的
"疑似目标"多半是杂波或已在别处重生,却会在滑行期按最坏速度膨胀成一个毒圈
(教科书多目标跟踪的确认逻辑;此改动在回放面把紧急规避降了 29%、真引擎面降 36%)。
**例外二**:类别为静物的轨迹是"在线建图"语义——看见过的树永远记住、位置冻结、永不删除
(遮挡不该抹掉已建的图)。

## 3. 跟踪与预测:卡尔曼滤波

代码:`metaurban/kf_tracker.py`(218 行)。每条轨迹一个跟踪器,x、y 两轴各一个独立的
**匀加速(CA)卡尔曼滤波器**,状态 = [位置, 速度, 加速度];z 轴不滤(行人不飞,z 恒取检测值,vz=az=0)。

**离散化是精确的**:状态转移 `F = [[1,dt,dt²/2],[0,1,dt],[0,0,1]]`,
过程噪声用"白 jerk"的精确积分(Van Loan):

```
Q = q_jerk · [[dt⁵/20, dt⁴/8, dt³/6],
              [dt⁴/8,  dt³/3, dt²/2],
              [dt³/6,  dt²/2, dt   ]]        (q_jerk = 2.0)
```

精确离散化的意义:**三个 0.1 s 步与一个 0.3 s 步数学恒等**(回归测试验证数值一致到 10⁻¹²;
另有"默认节拍路径逐位不变"的严格测试),所以变节拍(渲染面 0.1 s、回放面 0.3 s)不会引入模型误差。

**初始化(踩坑后的版本)**:第一次检测只置位置,速度方差给 100(明确表示"不知道",
旧版给 1 等于断言"速度≈0",快车的第二次更新会带来荒谬的创新量);第二次检测做
**两点差分重初始化**:`v₀ = (z₂−z₁)/dt_eff`,并写入精确的协方差
`[[R, R/dt],[R/dt, 2R/dt²]]`(dt_eff 计入中间漏检的滑行时间)。

**滑行(coast)**:没配上检测的拍只做时间更新——状态照惯性外推、协方差增长。
位置不确定度 `pos_sigma` 随滑行上升,供"出锥记忆目标"的半径膨胀使用。

**输出给证书的预测多项式**:`c(t) = c₀ + v·t + ½a·t²`(次数 ≤2,恰好是证书核吃的形式),
加速度输出钳在 ±2 m/s²(长视界下 KF 加速度噪声大)。
**部署实际用匀速(CV)模型**(`PRED_MODEL=cv` 默认):加速度清零后再喂证书与规划器——
因为标定(第 4 节)是对 CV 预测的误差收割的,**预测器与标定必须是同一个函数**;
且对走走停停的行人,CA 的加速度项常常过冲,CV 误差反而更小。

**成熟度**:更新次数 n ≥ 2 才算"就绪"(速度才有意义);n ≥ 4 才算"成熟"。
成熟与否决定下游用哪套误差余量(第 4 节)和是否被精细功能采信(第 5 节)。

## 4. 预测误差余量:统计标定(conformal)

预测一定会错。这一节回答"错多少",并给出**不依赖任何分布假设**的保证。
现行第三代方法(代码 `metaurban/calibrate_v3.py`,157 行;发布文件 `calib_v3.json`)。

### 4.1 保证的形式

把每类目标的危险半径按预测时长 Δ 加一条直线余量:

```
成熟目标:   余量(Δ) = λ̂·(b + v·Δ)            (λ̂ 同乘截距与斜率)
新目标:     余量(Δ) = λ̂·b_y + VCAP·Δ           (斜率钉死物理速度帽,永不乘 λ̂)
静物:       余量(Δ) = λ̂·b_s                     (不随时间长)
```

**保证**:标定航次与新航次统计上同类(可交换)时,
**P(新航次里存在任何一条合格的预测误差记录逃出其余量) ≤ ε**。
这是"每航次上确界"口径——不是逐条记录 95%,而是整个航次一条都不逃的概率 ≥ 1−ε。

### 4.2 残差收割:部署在环

代码:`metaurban/harvest_v2.py` + `replay_core.py` 的收割钩子。要点:

- **部署在环收割**:真实感知前端全开(锥/遮挡/漏检/噪声/无身份关联),完整决策栈在环飞行,
  **预测器与部署同款(CV)**——关联错误、间歇、滑行全部体现在误差里。
  诚实申报:收割航次飞的是默认(v1)决策栈,现役栈的决策层开关(锦标赛 v2、未确认轨迹限时等)
  收割时未开;标定航次与消费栈之间的这点差异是可交换性假设的一部分,须显式申报。
- 每拍、每条就绪轨迹、每个预测时长 Δ ∈ {0.00, 0.05, …, 1.05}(22 点网格)记一行:
  `e = ‖目标真实位置(t+Δ) − 预测位置‖`(平面二维范数)。
  成熟行的预测器 = 部署同款 CV 外推;**新目标行(n<4)与静物行的预测器 = 冻结在当前位置**
  (即 e 直接就是对冻结中心的残差,标定端不再换算)。
- **合格(qualified)规则**:只有"未来物理上够得着无人机"的记录参与保证:
  `∃ Δ ∈ {0, 0.35, 0.70, 1.05}: ‖目标(t+Δ) − 无人机(t)‖ ≤ 3.0·Δ + r + 0.35 + 0.50`
  (3.0 = 无人机最大速度;可达球语义:真肇事者在最后一次认证时必然满足)。
- **歧义关联整行丢弃**(最近的真值目标 ≤0.5 m 且第二近的至少远 0.5 m 才入账);
  身份互换的极端情形显式划出保证范围。
- 工程:分片并行、逐集落盘清单(训练机会硬件崩溃)、配置文件 sha256 锁
  (标定池、种子、规则全部预注册,改一个字节就拒跑——防"结果购物")。

### 4.3 分数与秩(第三代:冻结形状 + 单缩放系数)

前两代的教训(详见 4.5):想给每组(类别×成熟度×滑行状态)各估一套参数,
数据永远不够,估计误差直接毒害覆盖率。第三代的手术:

**第一步,冻结形状**(在独立的设计数据集 designC 上拟合,与标定折不相交):
逐 Δ 取误差的 90 分位(新目标臂取 95 分位),斜率用 Theil–Sen(成对斜率的中位数,抗离群),
截距取"包络式":`b = max_Δ (q90(Δ) − v·Δ)`(每个网格点都被压住)。
实拟数值:行人成熟 (b,v)=(0.308, 1.003),车辆成熟 (0.386, 0.999),静物 0.27(地板钳出),
行人新目标 b_y=0.423(帽 2.2 m/s),车辆新目标 b_y=0.440(帽 11.0 m/s)。
另有稳定门:designC 拟出的斜率对独立登记的历史斜率漂移 >10% 即整体拒发(fail-closed)。

**第二步,给每行记录打一个无量纲分数**(形状固定后,分数是标定前就定死的函数):

```
静物:       s = e / max(b_s, 0.05)
新目标:     s = (e − VCAP·Δ) / b_y          (e 已是对冻结中心的残差;可为负)
成熟:       s = e / max(b + v·Δ, 0.05)
```

**第三步,每航次取上确界,单一共享秩**:
航次分数 `S_f = max{s_i : 该航次全部合格行}`;有记录但**零合格行**的航次记 −∞ 且计入 n;
整段没产生记录的航次不进 n(B7 实飞 69 个航次,22 个零记录,入账 **n = 47**,清单逐集可见、
无静默删除;丢掉这类平凡覆盖的航次只会抬高 λ̂,方向保守)。对每档 ε 取
`k = ⌈(n+1)(1−ε)⌉`,`λ̂ = 第 k 小的 S_f`。实跑:**λ̂ = 1.623(ε=0.10)/ 3.164(ε=0.05)**。
k > n 时该档整体不发(消费端按缺键 fail-closed)。

**为什么这样设计**:全部估计风险(形状拟错、样本不够)都被单标量 λ̂ 吸收,
而 λ̂ 是标准 split-conformal 的秩统计量——**形状拟错只让余量变宽(效率代价),
永远不让覆盖率变假(合法性代价)**。新目标臂的斜率钉死物理帽、不乘 λ̂,
杀掉了前代"新目标分数劫持秩 → 全体余量爆炸"的事故模式。

## 5. 规划器与预测占据

规划器 = 浙江大学开源 EGO-Planner,剥离 ROS 后编成独立库
(`ego/` vendored 源码 + `ego/capi/ego_capi.cpp` C 接口 + `metaurban/ego_bridge.py` ctypes 封装)。
**规划核心一行未改**(多项式初始化、B-spline 参数化、碰撞回弹优化、可行性检查全部原样);
为脱离 ROS,其占据地图模块被替换成一个 17 行的极简实现(下详),参数经垫片注入。
我们只控制喂给它的世界。

**规划器从我们这里看到什么**(`ego_bridge.EGOPlanner`):

- **栅格地图**(替换后的极简实现):每帧**整张重建**(无历史融合、无射线清空、相机位姿被忽略),
  喂进的点云被当作本帧障碍真值,按切比雪夫立方邻域膨胀(格 0.2 m;膨胀半径按面:
  回放 ours 0.45 m、回放 native/渲染面 0.3 m、真引擎面 0.1 m)。
  "深度相机视野限制"体现在**我们喂什么**,不在地图机制里。
- **replan(起点状态, 目标)**:内部做多项式初始化 → 均匀三次 B-spline 参数化(节距约 0.2 s)
  → rebound 碰撞回弹优化 → 可行性检查。**失败(包括"离目标 <0.2 m"这种无害原因)不写承诺轨迹**
  ——上一条承诺原样保留,`eval()/certify*()` 继续有效。这是"重规划失败就继续飞旧承诺"的基础。
- **eval(t)**:承诺 B-spline 在局部时刻 t 的 (位置, 速度, 加速度);时间原点 = 最近一次成功
  replan 的承诺时刻。

**喂什么(预测占据)**:对每条就绪轨迹,把圆柱面采样点(每次放置 12 方位角 × 3 高度层 = 36 点;
回放面默认放两帧共 72 点/目标,真引擎面单帧 36 点,渲染面方位角数按半径自适应)放在预测位置上。三种放法:

1. **默认**:CV 预测的 {t=0, t=0.3s} 两帧位置各一份(回放面);真引擎面只放当前位置一份;
2. **最近点占据(`CPA_CLOUD=1`,现役栈开)**:只对**成熟**轨迹,把圆柱放在
   "相对运动最近时刻"的预测位置:
   `t_cpa = clip(−(Δp·Δv)/|Δv|², 0, 2.5)`,其中 `Δp` = 目标−无人机,
   `Δv` = 目标速度 − 无人机满速意图速度。规划器于是学会**从预测的空隙里穿过去**
   (将横穿的人,其最近点足迹已经让出走廊)。回放面 +4.1 个百分点干净抵达。
   **只信成熟轨迹是血的教训**:全量采信版把计划送进了刚出生、KF 速度还偏低的加速车的路径(1 撞);
3. 渲染面:当前 + t_cpa 两环,半径只膨胀舒适项(0.45 m)、把头顶留空给飞越。

**要点(诚实)**:喂规划器的半径**默认是裸半径**(`RADIUS_CONSIST=0` 冻结行为),
而证书用全套膨胀(见第 6 节)——规划器可能提出证不过的路径,由决策层兜住。
这是刻意保留的旋钮:把 conformal 余量也喂进规划,会在规划层封死走廊(实测 A/B 更差)。

## 6. 连续时间安全证书(核心)

代码:`cpp/include/sando_cpp/bernstein_cert.hpp`(459 行 header-only,依赖 Eigen 与 `minjerk_traj.hpp`)
+ C 入口 `cpp/capi/cert_capi.cpp` / `ego/capi/ego_capi.cpp`。

### 6.1 要证明的命题

对承诺轨迹 p(t) 和每个目标,在信任窗 [0, t_hi] 内证明**圆柱析取**:

```
(水平避开"按预测运动的圆柱"  且  水平避开"冻结在当前位置的圆柱")
或者
(整段飞行都高于该目标的头顶净空面)
```

跨目标取"且"。水平避开 = 平面距离 `√(dx²+dy²) ≥ ρ(t)` 对窗内**每一个时刻**成立;
飞越 = `p_z(t) ≥ z_clear` 对窗内每一个时刻成立。两半都必须覆盖**整窗**——
明令禁止"猜一个接近时段单证那一段"。

半径与净空面的组成(`safety_layer.build_cylinders`):

```
ρ(t)      = r_目标 + 0.25(机体) + 0.10(舒适) + q(标定截距) + 0.473(渲染面跟踪余量,点质量面=0)
            + v_eff·(t + δ)                    ← 余量斜率把管子随时间撑宽
z_clear   = h_目标 + 0.30(伸手) + 0.25 + 0.30(垂直舒适) + q + 跟踪余量
            (净空面**不随时间增长**:KF 把目标垂直速度钉死为 0,常数地板是健全的)
δ         = 观测新鲜度(观测到承诺的延迟;默认 0.30 s 历史遗留,现役栈修正为 0.05 s)
```

二代及以后标定路径(`CALIB_V2=1`,现役栈)下:新目标(n<4)用"冻结盘"——中心速度/加速度清零
+ 新目标截距 + 标定文件里的增长率(按标定约定 = 物理速度帽);标定缺失的类别 fail-closed
(q=10⁶,附近什么都证不过,响亮报日志)。一代标定路径相反:缺类**静默回退**保守手值 (0.15, 0.6)。

### 6.2 数学:Bernstein 亏量

轨迹每段是多项式(EGO 三次样条 → 每段 Bezier;自研规划器五次),
目标中心是二次多项式 c(t) = c₀+vt+½at²,所以**平面距离平方 S(t) 也是多项式**。
把"危险半径平方减距离平方"写成亏量 D(t) = ρ²(t) − S(t),再换到 Bernstein 基:

**Bernstein 基的关键性质**:基函数非负且处处和为 1,所以
**多项式在区间上的值永远夹在系数的最小值和最大值之间**。于是:

```
所有 Bernstein 系数的上界 ≤ 0   ⟹   D(t) ≤ 0 在整段成立   ⟹   整段安全。
```

一次代数检查覆盖区间内**无穷多个时刻**——与 K 点采样门(样本间可漏)的本质区别。

具体装配(每段、每坐标):

1. 位置控制点与目标二次式都**升阶**到公共次数 m(升阶公式
   `b'_k = (k/(n+1))·b_{k−1} + (1−k/(n+1))·b_k`);
2. 相对位置 w = p − c 逐点相减,再**平方**:两个 n 次 Bernstein 相乘的系数是
   `S_k = Σ_{i+j=k} [C(n,i)C(n,j)/C(2n,k)] · w_i·w_j`
   (Chu–Vandermonde 恒等式保证权重和为 1,每个系数是乘积的凸组合);x、y(球版加 z)累加;
3. **时间增长的半径按精确多项式折进亏量**:ρ²(t) = (R + v_eff·(t+δ))² 展开成二次式
   `A·t² + B'·t + C'`(A=v_eff², B'=2Rv_eff+2v_eff²δ, C'=(R+v_eff·δ)²),
   逐段换元成 Bernstein、升阶到 2m 次,然后 **b = ρ² − S 先装配、再细分**——
   这是健全性关键:对常数半径可以细分 S 再与 R² 比,对时变半径必须先成亏量多项式
   (细分会重参数化子区间,时间对应关系丢失);
4. 系数有正的但可能实际安全 → **中点 de Casteljau 细分**递归(每层界以 4 倍速收紧到真曲线,
   最深 16 层);系数上界全 ≤0 即早退证过;
5. **信任窗裁剪**:整段在窗外的段直接不管;跨窗界的段对亏量做"左子曲线"裁剪
   (de Casteljau 在切点取左半),只留窗内部分;**窗内一段都没有 → 返回"未证明"**
   (什么都没证 ≠ 安全)。

### 6.3 浮点不说谎:区间算术

每个系数都以**外向取整的浮点区间**携带:先按最近舍入算,再各向外挪一个最小浮点单位
(`nextafter`);加减乘全是区间运算,连 1/2 这种精确有理数权重也照挪(轻微保守,绝对健全)。
判定用严格上界。结论:**算出来的"安全"必然是真安全**——浮点误差只可能让证书拒绝一个
实际安全的轨迹,绝不可能放行一个危险的。

### 6.4 三值判决

亏量系数的**下界**如果在某个子区间上全 > 0,则亏量在那一段被证明恒正——
这是"确实被挡死"的**反证见证**(refuted)。于是每次检查可给三种答案:
**证过 / 确实被挡 / 不知道**(包络太松或细分预算耗尽,只有这种情况加深预算还可能翻案)。
三值出口在回放面作诊断(区分"真堵"与"证书保守"),不驱动决策;真引擎面尚未接入。
其底层的"下界全正即早退"先前已作为一次约 2000 倍的性能修复落地
(真被挡的候选不再白细分到 16 层);三值判决只是把这个已有的见证零成本导出。

### 6.5 与规划器的解耦

证书核吃统一的"分段 Bernstein 控制点"(BSeg)。适配器(`metaurban/cert_bridge.py`):
幂基多项式(min-snap/自研)、降幂矩阵(GCOPTER)、**均匀三次 B-spline(EGO)——
每段 4 个 B-spline 控制点乘固定矩阵**:

```
b₀ = (P₀ + 4P₁ + P₂)/6      b₁ = (4P₁ + 2P₂)/6
b₂ = (2P₁ + 4P₂)/6          b₃ = (P₁ + 4P₂ + P₃)/6
```

这是精确换基(Bezier 与原 B-spline 段逐点相等),不引入松弛;转换本身用普通浮点,
飞越证书提供 `bez_pad` 外垫吸收其舍入(默认 10⁻⁹ m——远超转换的 ULP 级舍入、物理可忽略的保守外垫),
水平证书把控制点当精确值
——这一不对称如实申报。同一证书核跑 EGO(三次,亏量 6 次)与自研五次(亏量 10 次),
是"规划器无关"支撑性质的字面证明。

**性能**:单次检查约 7 微秒(内核微基准台账,`bench_algo.py`);一拍内几十个候选 × 每目标 3 次内核调用毫无压力。
margin 语义注意:水平证书的裕度单位是**米²**(距离平方域),飞越证书是米,不可混比。

## 7. 决策层:方向×速度锦标赛

代码:`metaurban/safety_layer.py`(699 行,三个测量面共用的决策实现;
渲染面调同一函数但显式传自己的 8 档速度网格,且保留旧版锦标赛副本可回退)。
统一入口 `maneuver_decide_v2`(现役;`v1` 为冻结基准)。每拍:

### 7.1 候选网格

- **方向**(每个方向一次 replan,这是贵的操作):
  直行、左偏 25°、右偏 25°、左偏 50°、右偏 50°、飞越(终点上空)、原地爬升。
  胡萝卜点 = 当前位置 + L·旋转(目标方向, 偏角),L = min(7.5 m, max(距终点, 1 m))。
  可选扩展(默认关):边前进边爬升(soar)、瞄准横穿者尾流的空隙点(gap carrot)。
- **速度档**(同一条样条,证不同的执行速度,便宜):默认 (1.0, 0.6, 0.3);
  现役栈加 **0.15 倍爬行挡**(`SPEEDS_CRAWL=1`)——全速证不过时还能以 0.45 m/s
  认证地慢慢挪,而不是停成活靶。回放面上一批 1–3 拍的"闪烁式"紧急规避被它吸收。
  (渲染面显式传自己的 8 档网格,此挡在渲染面无效——见 §13。)

### 7.2 减速候选怎么证:时间伸缩恒等式

以 s 倍速飞同一条样条,等价于"无人机原速飞、世界快 1/s 倍"。
于是减速候选喂**同一个证书**做代换:

```
目标速度 → v/s,   信任窗 → s·τ,   余量斜率 → v_eff/s,   新鲜度 → δ·s
```

在 CV 预测下(加速度≡0,现役部署)数学严格等价(把世界时间 t 代换为样条时间 u = s·t),
无需新证书核;实现里障碍加速度被置零,若切换 CA 预测此恒等式不完整(如实申报)。
减速证书只保留"预测运动"那一半合取(冻结当前那一半会禁止一切让行)。
静物的管子参数对时间伸缩不变,但证明窗 s·τ 随减速缩短——减速可以把静态冲突
**合法地推出证明窗**(推迟而非消除;逐拍逼近后仍会降档直至紧急规避)。

### 7.3 速度换证明窗(`TAU_SPEED=1`,现役栈开)

证书窗本不必恒为 0.75 s:窗只需覆盖"一拍 + 从当前承诺速度刹停的时间"。
承诺速度 = 3s m/s、刹车 6 m/s² → 刹停 s/2 秒:

```
t_c = min(0.75, 0.30 + 0.5·s + 0.05)
```

爬行挡只需 ~0.4 s 的窗 → 余量少长一半 → **"连悬停都证不过"的拍变成"认证的慢速前进"**。
降速由此成为换取可证明性的连续杠杆(回放面单发 +13.9 个百分点干净抵达,战役最大单项)。

### 7.4 排序与防抖

- **字典序 (速度档, 进度)**:先比速度档,再比"伸缩后 s·τ 时刻沿目标方向的位移"。
  满速绕行胜过任何减速直行(纯进度分是近视的:慢而直会赢短期、然后一直慢);
  满速直行证过立即收工。
- **粘性(在位者优先)**:胡萝卜点在世界系冻结(渲染面因长航线改为"偏角随目标方向重锚"),
  没到就优先续飞;速度**降档即时、升档每拍最多一格**(刹车不能等,松刹要缓)。
  每 3 拍做一次"升级探测":想换回更直的方向,必须通过**加严的证书**(新鲜度项 δ 加严 0.15 s,
  即管子按各类斜率再厚 v_eff×0.15)且不降速——边缘证书不许把无人机从刚承诺的绕行里拽出来。
- **逃逸压力预触发(`ESC_TRIG=1`,现役栈开)**:前向 ±70° 锥内、正在逼近的最近威胁,
  其净空连续收缩(<2.5 m 且收缩率 >0.8 m/s)时,把逃逸族候选(soar/大偏角/飞越)排到队首。
  **只改排序,每个候选照样过证书**——语义:包围圈闭合后一切候选全灭,逃逸必须趁还证得过时走。
  (在位者续飞仍然优先:逃逸族实际在"在位者证不过"或每 3 拍的升级探测拍才被评估。)
- **收尾健全性补丁**:锦标赛循环会覆写规划器手里的样条,胜者若不是最后一次 replan 的,
  会重新 replan 并**重新认证**;重认证失败直接落紧急规避——绝不飞没重证过的样条。
  (已知缺口:恢复 replan 自身的失败未被检测,此时飞的是循环残留样条——仍经过重认证,
  但方向标签可能与实际不符。)

### 7.5 紧急规避(evade)

全部 (方向×速度) 候选都证不过时的无保证兜底:朝离最近威胁的反方向逃
(速度设定点 = 满速水平反向,垂直分量为零;爬升通过位置设定点的 z 项实现),
只逃**感知里有的**目标(逃看不见的等于作弊)。
每次触发计一次账;发生即该集"不干净"。渲染面语义不同:evade 改叫 hold(悬停),
密集静物场景绝不盲逃。

## 8. 执行器:三个测量面

**回放面**(`replay_core.py`):点质量。沿承诺样条取一拍设定点,
减速档按**时间重参数化**执行:位置取 s·0.3s 处、速度×s、加速度×s²(链式法则)。

**渲染面**(`render_3d_video.py`):真四旋翼模型(质量 0.95 kg、外环 PD+前馈
`a_des = 10·(p_ref−p) + 6.2·(v_ref−v) + a_ref`、倾角限 55°、姿态一阶滞后 60 ms、

执行侧两件事值得写:

- **刹车参考场(`HOLD_DECEL=1`)**:悬停保持的默认实现是"位置参考每子步锚回当前位置、
  速度参考清零"——位置误差项恒为零,阻尼项 `a_des = −6.2·v` 一步索要全部减速 → 猛俯仰。

- **plan→flown 跟踪余量**:证书证的是计划,四旋翼飞的带惯性/倾转过冲。渲染面把
  逐航次统计的跟踪误差分位(0.473 m,ε=0.01)加进证书半径,并另有两道"前推仿真闸"
  (深拷贝当前真实状态、以 0.02 s 步跟踪样条 1.2 s,把**将被飞出的路径**对静物和目标做距离检查)。

## 9. 端到端保证:组合定理

代码:`metaurban/phase5_compose.py`;文档 `docs/composition-theorem.md`。
统计半边("预测误差不超余量",1−ε)和几何半边("误差不超余量就绝不撞",确定性)拼合:

> **定理(直白版)**:标定场景与测试场景可交换时,对新场景,
> **P(全程已认证飞行时段内发生碰撞) ≤ ε。**

**证明骨架**:碰撞若发生在认证后 W 秒内,则肇事目标当时必在"绑定距离"内
(`D_bind = (v_机 + v_类)·W + 1.6 m`,更远的窗内物理够不着),
且其某条预测误差必然逃出了余量(否则证书的几何部分排除碰撞)。
于是"认证后碰撞"⊆"存在绑定域内的误差逃出余量",而后者的概率被 split-conformal 秩控制在 ε。

**让定理落地的关键一招:重认证节奏**。episode 分数只对
`Δ ≤ W = 0.4 s`(一拍 0.3 s + 余裕)且 `离机距离 ≤ D_bind(类, 0.4)` 的记录取上确界——
因为系统每 0.3 s 重新认证,任何碰撞前 0.4 s 内必然刚通过一次证明,余量**只需覆盖 0.4 s
的预测误差**而非整个 0.85 s 视界。现行数字(2026-07-04 运行,感知升级后):

| 口径 | q₀(ε=0.05) | 余量@窗口 | 保留组覆盖 |
|---|---|---|---|
| 全局上确界(naive) | 6.144 | 6.99 m @0.85s | 0.953 |
| **节奏感知 W=0.4** | **1.054** | **1.45 m @0.4s** | 0.925(40 个 episode,样本小) |

约 4.8 倍紧缩——没有这一步无人机在街道上根本动不了。
(文档里的 3.18→1.02 m 是 07-03 感知升级前的旧运行,引用需锁版本;
另注:`compose_theorem.json` 的 provenance 日期是脚本硬编码常量,恒写 07-03,
运行版本以晋升件 `calib.json` 的 provenance(07-04)为准。)

**准确的统计口径(按代码,非文档)**:可交换单元是 **scenario**(场景整体分进
形状 20% / 标定 45% / 测试 35% 三组,episode 聚在场景内,按 episode 切会泄漏几何);
episode 是打分与覆盖计数单元;无绑定行的 episode 从分母剔除(平凡满足,偏严口径);
斜率 v_eff 取自独立形状组各时长 90 分位点的最小二乘拟合(0.996;截距弃用),
**合法性完全由 q₀ 的秩承担**。
晋升 = 人工显式拷贝进部署读的 `calib.json`(每类都填同一条节奏管;分类管因车辆样本饿死
q₀=∞,诚实弃用)。

**三本账**(防"证了一半冒充全证"):① 已认证飞行 → 上面的 ε;
② 重规划失败沿飞旧承诺 → 频率可测,按测得频率摊账(回放面每拍重规划,此支为空);
③ 紧急规避 → **无保证**,按暴露时长如实报告(结构性:能证的都到不了这步)。

## 10. 强化学习验证臂(证书盾)

代码:`metaurban/shield.py`(115 行)+ `ground_shield.py`(unicycle 版)。
目的:证明这套"标定余量 + 安全关卡"**不挑规划器**——套在纯 PPO 策略外面也有效。

**机制(与主线不同,如实区分)**:盾不调连续时间证书核,而是逐拍动作检查——
指令速度在 0.75 s 窗内匀速外推,与每条轨迹的 KF 状态(**滤波后的位置/速度,
不是原始检测**——必须与标定同锚点,否则覆盖保证失效)做 16 个采样点比较:

```
危险:∃ t_k ∈ {0, 0.05, …, 0.75}:  ‖相对位置(t_k)‖ < r + 0.25 + 0.10 + q₀ + v_eff·t_k
```

三级响应:**放行**(动作本身安全)→ **投影**(16 方向 × 2 速度共 32 个一步可达速度,
按目标方向投影降序,取第一个安全的)→ **刹车**(全灭:沿当前速度一步最大减速,
**未认证**,显式计数上报)。地面版把直线外推换成恒 (v,ω) 弧的解析式;安全检查与三级响应
**结构**同构,但投影候选集不同(3 档加速 × 5 档角速度共 15 条弧,按窗末位移朝目标的投影排序),
刹停为直线(ω=0)一步减速。

结果:碰撞 6.75% vs 裸策略 14.25%(400 集,Fisher p=0.0007),开盾还提高到达率;
训练时把标定冻结进环境,最优 6.0% vs 16.25%。此线已归档为支撑证据。

## 12. 进行中:在认证集合内规划(CPL-v3)

代码:`metaurban/local_lattice.py`(299 行);设计文档 `docs/design-CPL-v3-cert-local-planner.md`
(注意:代码与设计稿有多处实质偏离,以下全部按代码)。

**动机**:第 7 节的决策层是"离散挑候选"焊在连续规划器上,接缝天然犹豫;
一切平滑技巧都在给近视的仲裁者打补丁。根治 = **直接在被证明安全的轨迹集合里规划**,仲裁降为兜底。

**候选构造**:每拍生成一批 1.5 s 五次多项式"意图基元"(边值闭式解):
13 个航向(相对目标方向 0/±15°/±30°/±50°/±75°/±105°/±135°)× 5 档终速变化
(+1.2/+0.6/0/−0.9/−1.8 m/s)× 高度层(近前向航向 3 层,默认开)+ 悬停/前进爬升/原地爬升
+ 上一拍胜者(warm-start)+ EGO 全局引导基元(取 EGO 样条 1.5 s 处状态当终端,防局部极小)。

**每个候选变成"复合体"再整段开证**:

```
段1 意图基元的前 0.3 s(唯一会被飞的部分)
段2 单段五次刹停曲线(时长 = v/a_max + a_max/40;峰值加速度或加加速度超标则 1.3 倍加宽重解,最多 10 次)
段3 停稳保持 0.05 s(半径 ρ(t) 停了还在长,"停在障碍旁"必须也在证内)
t_cert = 三段总时长;certify_composite 以整窗对每目标证 (水平预测∧水平冻结)∨飞越
```

**递归可行性**:任何时刻系统握着一条"已被证明能安全刹停到静止"的完整退路;
每拍只飞证内前 0.3 s,飞完的状态恰是刹停段的起点。无一候选过证时,当拍新鲜构造+新鲜认证
一条刹停复合体(过 → 执行"brake";再不过 → 回放面落紧急规避 / 渲染面悬停)。

**评分(字典序)**:量化进度(意图基元 1.5 s 终点沿目标方向位移,0.15 m 桶)→
净空超额(裕度按该目标危险直径 2R 归一化的**无量纲**数,0.5 封顶——超出部分视为浪费,
拿去换直与快;注意不是 0.5 米)→ 平顺(对目标方向偏角 + 终速变化)。

**现状**:健全性锁死(10⁴ 场景零假证明);但"随时能刹停"的代价被量化到米:
悬停复合体的证明窗约 0.65 s(0.30 承诺 + 0.30 刹停 + 0.05 保持),窗内危险半径按
ρ = R + v_eff·(t + δ) 持续膨胀。渲染面标量口径的受控诊断(`diag_v3.py` 台账,R≈1.35、斜率 0.61):
行人约 1.75 m 内连悬停都证不过;回放面一代标定口径下更宽(R≈1.70、斜率 0.996、δ=0.30 → 约 2.65 m)。
旧决策层可 0.10 m 贴身而过——差距一个数量级以上;到达率 8/8 → 1/8。
三个设计级修法已诊断指向(刹停窗内换方向性/CV 预测消双重保守;"完全刹停"弱化为
"减速到可重认证态";对冲/近终点前的主动提前飞越)。**裁决:暂不替换现役栈**;
第四代标定(余量再瘦一档)与它配套一次转正。

## 13. 诚实申报:边界、死开关与已知不一致

**物理边界**:残余碰撞几乎全是 45° 锥外 8.3 m/s 侧后方快车(无人机 3 m/s)。
360° 全知消融**一次都没减少**——1.9 s 预警 × 3 m/s 机动性对 8.3 m/s 扫掠无逃逸解。
信息论审查确认只有两类机制能碰它(锥外证据:影子/第二传感器;或检测前降速)。
单传感器设定下写入失效包络,不再追。

**保证的边界**:紧急规避无保证(结构性;按暴露如实报);保证是分布内的
(换生成器/传感器规律必须重标定;标定节拍必须匹配部署节拍——早期最大的坑);
身份互换的极端情形在保证外(歧义关联行被丢弃);组合定理 ε=0.10 档保留组覆盖 0.700
(40 episode,样本小 + 可交换近似)如实报告。

**面间不一致(已知,待修)**:渲染面只读一代标定文件(`calib.json`),二/三代标定与
`SPEEDS_CRAWL`(渲染器显式传 8 档速度,爬行挡形同虚设)在渲染面不生效——
**渲染面行为不能当评测证据,评测数字不能配渲染面画面口径**。
喂规划器的半径与证书半径默认不一致(`RADIUS_CONSIST=0`,刻意冻结)。

**死开关/无效路径(代码考古,防止误引)**:回放面与真引擎面的 `NIS_GATE` 全线打不响
(轨迹对象缺 `nis_ewma` 属性,恒 0;`SIGV_GATE` 可用);`CALIB_EPS` 在回放面不被消费
(loader 走默认 ε=0.05;只有真引擎面/盾读它);CPL-v3 的速度信任窗算了没用(`tau=None` 传死)、
平滑权重第三项未参与评分;地面盾的 (速度×角速度) 弧候选集不含减速弧
(系数全正使减速分支不可达;无人机盾的 16 向候选含减速);`maneuver_decide_v2` 在文件里
被定义两次(核心 + SPEED_SLEW 包装,外部调用进包装)。

**默认值纪律**:所有战役改进都以 env 开关落地、**默认关**;默认路径对冻结基准逐字节回归
(`regress_frozen_ours.py`,改跟踪/感知前后哈希必须全同)。现役最优栈 = 附录 B 的开关组合,
不是代码默认。

**工程铁律**:三个 C 接口库(`sando_capi.so`/`ego_capi.so`/`cert_capi.so`)不在 CMake
构建图,改 C++ 必须手动重编否则静默用旧行为;标定配置 sha256 预注册锁;
训练机 CPU 有硬件故障,一切长任务逐集落盘可续跑;每个算法主张必须配 3D 对比视频取证;
汇报任何数字必须标测量面。
