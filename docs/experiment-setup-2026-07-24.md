## 2. E0 卫生门(任何矩阵开跑之前,半天内的活)

## 3. E1 北极星矩阵(主战役)

- **20 seed × 3 臂(GT_XY / KF / ORACLE_THIN)× EGO_DECIDE=guide,全部在当前 HEAD 重跑**。

  大重构改了静态处理、A* 确定性、挡位梯、回滚路径,旧 fail 链的病根大半已换。
- 产物老五件套:mp4 + log + explain jsonl + attrib + 账本;驱动器沿用断点续跑式
  (scratchpad/sweep_gtxy.sh 的模式),并行守上限(全 3D×2 / headless×3)。

## 5. E4 主张面:guide 与 final100 的关系(需要拍板的设计决策)

**一个容易被忽略的陷阱**:final100 的 conformal 覆盖主张(λ、T1 表)绑定的是冻结栈的
飞行策略——飞行路径决定感知锥朝向和距离,进而决定残差分布。guide 臂改变飞行路径,
**λ 对 guide 臂不再有效**,不能"换个臂沿用旧管子还声称覆盖"。三条路:

1. **guide 不进论文**(当前默认):论文用冻结栈,guide 是工程下一代。最省,主张链完整。
2. **guide 进论文** → 新预注册:cal60 场景在 guide 策略下重收割、重标定 λ,test 作为
   新 plan 重开一次考。整套产线现成(harvest_v3/calibrate),成本≈一轮 final100 重跑。
3. 折中:guide 只上 T3 行为表(干净抵达/碰撞/时间),**不主张覆盖**,管参数用 THIN
   明文声明(THIN 从不主张 conformal 覆盖,这条路径是现成合法的)。

与 guide 无关但同属主张面的欠账,可并行推进:
- **native 锥对齐基线**(T3 首项,九月欠账,视力手术后一直没重打);
- GT_XY 异常案:EGO_EXPLAIN 已翻案(6d193e3),确认结案后解除"GT-xy 不进论文"的封印,
  或维持封印并在诚实边界段披露。
